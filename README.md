CodeAlpha Bioinformatics Internship – Task 1

 DNA/Protein Sequence Analysis

 Objective
To analyze a biological sequence using BLAST.

 Tools Used
- NCBI BLAST
- FASTA

 Methodology
1. Selected the biological sequence.
2. Converted/prepared the sequence in FASTA format.
3. Performed BLAST analysis.
4. Analyzed the BLAST results.
5. Identified the best matching sequences.

Results
The BLAST search was performed and the obtained hits were analyzed based on sequence identity, query coverage and E-value.

 Conclusion
BLAST analysis helped identify similar biological sequences and provided information about the possible identity and characteristics of the query sequence.
